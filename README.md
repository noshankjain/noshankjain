## Projects

### Smart Surveillance – Real-Time Collaborative Security System  
An AI-powered surveillance platform that analyzes live camera feeds and detects abnormal human behavior.

- Detects and tracks people using **YOLOv8 + DeepSORT**  
- Uses **collaborative agents** to analyze loitering and fall incidents  
- Inter-agent communication through **Redis Pub/Sub**  
- Streams alerts and bounding boxes to a **React live dashboard**  
- Supports **Webcam, CCTV RTSP, and DroidCam phone camera input**

---

### Urban Pulse – Global Real-Time IoT Sensor Network  
A full data-engineering pipeline for monitoring environmental conditions across major cities worldwide.

- Simulates **30+ concurrent IoT devices** using MQTT  
- Real-time ingestion via **RabbitMQ** with ETL orchestration in **Mage AI**  
- Stores geo-tagged AQI and temperature data in **PostgreSQL**  
- Visualizes data on an interactive **Streamlit geospatial dashboard**

---

### Matter Hub – Legal Case Management Dashboard  
A full-stack legal workflow management system designed for law firms to streamline case tracking, document handling, and client management.

- Interactive **Kanban board** for tracking case stages (Intake, Discovery, Trial, Closed) using drag-and-drop  
- Secure **PIN-protected Document Vault** for managing sensitive files  
- Comprehensive **Client Directory** with case associations  
- **Billing & Time dashboard** for tracking billable and unbilled work  
- Built with a **decoupled architecture** (React + Express REST API)  
- Uses **Prisma ORM with PostgreSQL (Neon)** for scalable data management  
- Deployed with **Vercel (frontend)** and **Render (backend)**
